# Laporan Audit Forensik dan Perbaikan Velum

Tanggal audit: 2026-09-19. Repository: `velum-tunnel/velum`. Fokus audit: correctness aplikasi, jaringan, state machine, persistence, lifecycle Android, dan validasi build. UI/UX tidak diaudit kecuali berdampak langsung pada fungsi.

## Kesimpulan

Audit menemukan beberapa kelas bug fungsional pada pembacaan respons jaringan, persistence terenkripsi, pemilihan endpoint, konkurensi state tunnel, callback lifecycle, dan integrasi komponen Android. Perbaikan diterapkan langsung pada working tree. Setelah perbaikan, unit test JVM, lint Android, APK debug, dan APK preview dengan R8/resource shrinking semuanya berhasil dijalankan secara lokal.

CI tidak dipakai sebagai alat uji. Tidak ada commit atau push yang dilakukan dalam sesi ini.

## Perbaikan yang Diterapkan

### Jaringan dan endpoint

Respons HTTP dan DoH sekarang dibaca dengan batas ukuran melalui `VelumIo.readUtf8Bounded`, sehingga server atau captive portal tidak dapat memicu alokasi memori tanpa batas. Body error upstream tidak lagi dimasukkan ke pesan exception yang dapat diteruskan ke log. Anggaran uji trace tujuh detik diterapkan ke setiap tahap request dengan timeout tersisa yang dibagi antara koneksi dan pembacaan.

Kandidat DoH dari storage divalidasi ulang sebagai IPv4, dideduplikasi, dan dibatasi jumlahnya sebelum dipakai untuk probing. Kandidat endpoint yang hanya terukur RTT tidak lagi langsung dipersist sebagai endpoint terpercaya. Endpoint pending baru dipromosikan menjadi `workingEndpoint` setelah handshake baru berhasil. Kandidat yang gagal dibuang dan cache endpoint yang sama diinvalidasi. Validasi endpoint hasil registrasi diperketat melalui normalisasi host dan port bersama.

### State machine dan konkurensi

Listener tunnel menggunakan ownership compare-and-clear sehingga Activity lama tidak dapat menghapus listener milik controller baru. State tunnel diperbarui di bawah lock yang sama sebelum callback dipublikasikan. Operasi down/restart membedakan transisi yang diminta aplikasi dari transisi eksternal, sementara intent generation mencegah operasi lama menghidupkan kembali tunnel setelah niat pengguna berubah.

Verifikasi handshake sekarang memakai baseline sesi, bukan hanya timestamp handshake yang lebih besar dari nol. Dengan demikian, handshake lama tidak dapat mengesahkan endpoint atau sesi baru. Jalur operasi stale pada controller menjaga indikator busy dan pending test agar completion lama tidak memadamkan status operasi baru. Executor monitor dibuat lifecycle-scoped dan dihentikan saat monitor dinonaktifkan.

### Persistence dan migrasi

Registrasi disimpan dalam satu `commit()` dan diverifikasi dengan read-back. `clear()` juga fail-closed bila commit gagal. Penulisan rekaman boot durable sekarang melempar error bila commit gagal, sehingga caller dapat mencatat kegagalan. Recovery storage tidak lagi menghapus file terenkripsi pada exception generik. Migrasi legacy hanya memindahkan tipe yang dikenal, memvalidasi isi `Set`, menghapus key source hanya setelah destination commit berhasil, dan mempertahankan key yang tidak dikenal.

### Integrasi Android

Quick Settings tile kini membuka `Prefs` di dalam failure path, sehingga `KeystoreUnavailableException` tidak lagi keluar dari executor sebelum tile diperbarui. Penyimpanan daftar exclusion mempertahankan package yang tidak terlihat oleh package-visibility policy Android; hanya package yang terlihat pada layar yang dapat diubah oleh checkbox. Ini mencegah pilihan split-tunneling tersembunyi terhapus diam-diam.

## Perubahan Utama

Perubahan mencakup `VelumApi`, `EndpointProbe`, `VelumFormat`, `VelumRegistration`, `VelumIo`, `VelumProbePolicy`, `Prefs`, `VelumMigration`, `VelumTunnel`, `VelumConnectionContract`, `VelumController`, `ReconnectMonitor`, `VelumTileService`, dan `AppExclusionActivity`. Regression test baru ditambahkan pada `VelumIoTest`.

## Bukti Verifikasi Lokal

| Verifikasi | Hasil |
|---|---|
| `:app:testDebugUnitTest` | LULUS; seluruh test JVM selesai tanpa kegagalan |
| `:app:lintDebug` | LULUS; laporan lint berhasil dibuat |
| `:app:assembleDebug` | LULUS; APK debug multi-ABI berhasil dibuat |
| `:app:assemblePreview` | LULUS; R8 dan resource shrinking berhasil |
| `git diff --check` | LULUS; tidak ada whitespace error |

Toolchain yang dipasang secara lokal adalah OpenJDK 21, Android SDK command-line tools, Android platform/build tools, dan `local.properties` yang menunjuk ke SDK lokal. Warning yang tersisa hanya deprecation dari AndroidX `EncryptedSharedPreferences` dan `MasterKey`; tidak ada lint error atau compile error.

## Batas Verifikasi

Repository tidak memiliki instrumentation test (`app/src/androidTest`), emulator, atau perangkat Android yang tersedia di sandbox. Karena itu, callback `VpnService`, boot broadcast timing, Quick Settings lifecycle, keystore corruption, captive portal nyata, dan perpindahan network belum dapat dibuktikan pada perangkat fisik. Kode untuk jalur tersebut sudah dikompilasi, dilint, dan diuji secara statis; verifikasi perangkat tetap diperlukan sebelum rilis.
